# knowledge-locator 示例

以下示例展示该技能在面对不同输入时的典型输出形态。

---

## 示例 1：单一术语，单一知识树

**用户输入：**

> 梯度下降

**技能输出：**

这条知识点在知识树中的位置：

`数学 / 高等数学 / 最优化 / 数值优化方法 / 梯度下降`

梯度下降是一种"找最低点"的算法——想象你蒙着眼站在山坡上，每次都用脚探一探哪个方向最陡峭，然后朝那个方向往下迈一步，反复如此直到走到谷底（也就是最优解）。它几乎是所有现代 AI 训练背后最基础的"下山"动作。

---

## 示例 2：单一术语，跨多个知识树

**用户输入：**

> 梯度

**技能输出：**

这个术语同时出现在几棵不同的知识树里：

**【树1】** `数学 / 高等数学 / 多元微积分 / 向量微积分 / 梯度`
梯度是一个向量，指向函数值"上升最快"的方向，长度代表上升的速率。它是微积分里描述"变化快慢与方向"的基本工具。

**【树2】** `计算机科学 / 人工智能 / 机器学习 / 模型训练 / 优化算法 / 梯度`
在 ML 语境里，梯度表示"模型误差随各个参数变化的方向"——它告诉你该把每个参数往哪个方向调，才能让误差下降。

> 💡 两棵树其实是同一回事：ML 里的"梯度"，就是数学定义直接套用到"误差函数"上。看到这里，你就清楚后续该往哪棵树深挖了。

---

## 示例 3：一段文字描述（提炼后再定位）

**用户输入：**

> 我看一篇讲 AI 的文章，说神经网络能"自己学会"东西，靠的是一个叫"反向传播"的机制，但我完全不知道这是什么。

**技能输出：**

先从你的描述里提炼出要定位的核心概念：**反向传播（Backpropagation）**。

它在知识树中的位置：

`计算机科学 / 人工智能 / 机器学习 / 深度学习 / 神经网络训练算法 / 反向传播`

反向传播回答的是这样一个问题：当神经网络答错了一道题，它怎么知道"该怪罪"前面哪一层、哪个参数？它从最终的误差出发，一层一层往回算，把"责任"按比例分摊到每个参数上，告诉网络每个参数该往哪个方向微调。可以说，没有它，深度学习就无法被训练。

> 🔍 想顺着这条路径继续探索，可以重点看「神经网络训练算法」这一层，那里有梯度下降、损失函数等紧邻的概念等着你。
