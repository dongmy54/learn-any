# github-explorer 进化日志

记录该技能每次自我进化的时间、原因与改动，便于追溯与回滚。

## [2026-07-11] 第 1 次进化
- **触发场景**：用户要"找好用的 Go AI agent 库"，调用中暴露两个问题——①字段速查表把 `gh search repos` 的正确字段 `stargazersCount` 误标为"错误写法"，导致首次搜索报 `Unknown JSON field`；②`ai agent` + `--language go` 首轮结果全是应用产品（1Panel/pentagi/KrillinAI 等）而非开发框架，真正要找的 eino/langchaingo 没出现。
- **改动**：
  - SKILL.md「字段速查与避坑」：新增 `gh search repos --json` 与 `gh repo view --json` 字段集对照（star/fork 差一个 s），并修正原表把 `stargazersCount`/`forksCount` 标为错误写法的误导。
  - SKILL.md「工作流程·第三步」：补关键词策略，指导用 `framework`/`sdk` 限定词或按已知库名补搜，避免业务词按 star 排序混入应用产品。

## [2026-07-11] 第 2 次进化

- **改动**：

  - **去重**：精简「绝对不能做的事」第 6 条为第 5 条（字段名避坑已在【字段速查】详述，不重复展开）；合并核心原则与工作流的重叠表述。
