# Go 编程语言知识地图

## 🌲 核心主干概览

```
Go 语言
├── 基础语法（骨架）
├── 并发模型（灵魂）
├── 工程实践（落地）
└── 生态工具（武器）
```

### 📖 主干速览

- **1️⃣ 基础语法（骨架）**
  Go 语言的地基，包括类型、控制流、函数与接口。语法极简、关键字少，是写出任何 Go 程序的前提。掌握它你就能读懂大多数 Go 代码。

- **2️⃣ 并发模型（灵魂）**
  Go 区别于其他语言的核心竞争力。通过 Goroutine 和 Channel，用"通信代替共享内存"的方式轻松实现高并发。这是选择 Go 的最大理由。

- **3️⃣ 工程实践（落地）**
  把语言能力转化为可维护的真实项目，涵盖项目结构、错误处理、测试和标准库。决定了你的代码能否在团队和生产环境长期运行。

- **4️⃣ 生态工具（武器）**
  Go 自带的工具链与主流第三方框架，负责依赖管理、构建、格式化和快速搭建应用。让开发效率倍增、少造轮子。

## 1️⃣ 基础语法 (2周)

### 1.1 类型与变量
- ⏱️ **1天** | 🎯 **定义数据结构的基础** | 🔗 **无前置依赖**

  *（复杂分支示范：第 3 层按子主题分组）*

  - **基本类型**
    - 数值：int / int64 / float64
    - 文本与布尔：string, bool
    - 零值机制（无需手动初始化）
  - **复合类型**
    - array（定长）vs slice（变长，最常用）
    - map（键值对）
    - struct（自定义结构体）
  - **指针**（非必须但建议理解）
    - `&` 取地址 / `*` 解引用
    - 值传递 vs 引用语义

### 1.2 控制流
- ⏱️ **2天** | 🎯 **编写逻辑分支与循环** | 🔗 **依赖：1.1**

  *（简单分支示范：只到第 2 层，一组要点即可）*

  - if/else，switch（无括号写法）
  - for（Go 唯一的循环关键字）
  - defer（资源清理惯用模式）

### 1.3 函数与方法
- ⏱️ **3天** | 🎯 **代码复用与组织** | 🔗 **依赖：1.1, 1.2**
  - 函数定义：多返回值、命名返回值
  - 方法：receiver 理解（值 vs 指针）
  - 闭包与匿名函数

### 1.4 接口
- ⏱️ **3天** | 🎯 **解耦与多态** | 🔗 **依赖：1.3**
  - 接口定义与隐式实现
  - 空接口 interface{} 与类型断言
  - 常用标准库接口（io.Reader/Writer, error）

### 2.2 Channel
- ⏱️ **4天** | 🎯 **Goroutine 间通信** | 🔗 **依赖：2.1**

  *（复杂分支示范：第 3 层按子主题分组）*

  - **基本操作**
    - 创建：`make(chan T)`
    - send / receive / close

  - **遍历**
    - range 持续接收直到 close
